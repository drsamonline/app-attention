Attention

A focus session, one tap per interruption, and the report that shows where the drift actually happens. It records and reports; the judging is yours.

Open Attention
Status Built and working offline: a session with a named task and a length; six one-tap labels; every interruption stored with the minute and the clock time; a clock that never pauses; a drift report by hour of the day and by label, with the worst hour marked; and a week export that re-imports to the same worst hour.
Release: Windows EXE, Android APK and Linux binary, built from this source in CI — app-latest.
Not built: site blocking, app blocking, notifications, or anything that polices your time. There is no score anywhere in it.

What it does

  • Logs an interruption in one tap, with the minute and the clock time — because writing it down must not cost you the session.
  • Keeps the clock running: the session ends at its length, not when the interruptions stop.
  • Reports drift by hour of the day, and by what it was, with the worst hour marked.
  • Exports a week with one row per session; re-importing it reproduces the same worst hour.

What it will not do

  • Score your day. There is no score, grade, rating or streak in the engine.
  • Block a site or an app. There is no blocklist anywhere.
  • Run an untitled session. A ledger of untitled sessions cannot show a pattern.
  • Count an interruption with no elapsed time as zero.
  • Compute a pattern from a session it could not keep.
  • Start an empty ledger over an unreadable one. That would read as a day with no drift at all.

When things go wrong

CaseWhat happens
Bad inputNo task → refused. No length → refused. An interruption with no elapsed time or no label → refused.
No networkNothing changes; the timer and the log are on the device.
Storage full or unavailableThe session runs but is not written, and the app says the ledger will not have it — the pattern is never computed from a session that was not kept.
Corrupt saved stateReported and offered for export; never replaced with an empty ledger.

How to run it

  • Here: play/index.html, or install it from your browser's menu.
  • Offline file: open docs/play/index.html straight from disk.
  • Tests: node tests/self-tests.js — the spec's countable done-means is asserted there.
